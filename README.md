# Inglés Técnico II — Study App

Interactive offline study app built for the English II course of the 
Tecnicatura Superior en Desarrollo de Software at I.S.P.R.M.M., Formosa, Argentina.

## What it does
A self-contained Progressive Web App (PWA) designed to practice technical 
English for software development exams. Works fully offline and can be installed 
on Android from Chrome.

## Content
- **Section 1 — Grammar:** Passive Voice (Past Simple, Past Continuous, Present 
  Perfect), Zero & First Conditional, Technical Vocabulary, was/were drill
- **Section 2 — Problem Situations:** Transport App, Library Management System, 
  NimbusCloud Incident Response, Professional Profile, ShopSmart Security Incident
- **Section 3 — Troubleshooting:** Technical vocabulary and incident resolution workflow

## Tech stack
- Vanilla HTML + CSS + JavaScript (no frameworks, no dependencies)
- PWA with Service Worker for full offline support
- localStorage for progress persistence across sessions

## Topics covered
`Passive Voice` `Modal Verbs` `Conditionals` `SRS / Requirements Engineering` 
`Incident Reports` `Technical Translation` `Troubleshooting`

## How to install on Android
1. Open the GitHub Pages URL in Chrome
2. Tap "Add to home screen" or "Install app"
3. Works offline after first load
